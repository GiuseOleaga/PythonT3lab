## User Experience Flow

### Startup
```
App Launch
    ↓
Load Settings (JSON file)
    ↓
Initialize Theme Engine
    ↓
Generate Stylesheet
    ↓
Apply Theme
    ↓
Display Main Window
    ↓
Ready to Use
```

### Customization
```
Click ⚙️ Settings
    ↓
Settings Dialog Opens
    ↓
Select Tab
    ├─ General → Manage Files/Logs
    ├─ Theme → Pick Dark/Light/System
    ├─ Colors → Customize 6 Colors
    └─ About → View App Info
    ↓
Make Changes
    ↓
See Live Preview
    ↓
Close Dialog
    ↓
Settings Auto-Saved
    ↓
Theme Applied Instantly
```

### Theme Switching
```
Normal Usage (No Restart)
    ↓
User Opens Settings
    ↓
Selects Different Theme
    ↓
Live Preview Shows New Theme
    ↓
Close Settings
    ↓
BOOM! New Theme Applied
    ↓
Continue Using App
    ↓
Changes Persist on Restart
```
