# Quick Start - New Professional GUI Features

## 🎯 Get Started in 30 Seconds

### 1. Launch Application
Run `main.py` as usual. The app starts with your saved theme preference.

### 2. Click Settings Button
Look for the **⚙️** button in the top-right corner of the sidebar.
- Click it once to open Settings
- Settings dialog appears with 4 tabs

### 3. Explore Settings Tabs

#### 🏠 **General** - File & Log Management
- See save path and logs location
- Click 🗂️ to change save folder
- Click 📄 to view logs
- Click 🗑️ to clear logs

#### 🎨 **Theme** - Choose Your Look
- Select 🌙 Dark (professional dark)
- Select ☀️ Light (clean bright)  
- Select 💻 System (auto-detect)
- Click buttons to see preview
- ✨ Changes apply instantly!

#### 🌈 **Colors** - Customize Everything
- Click any color button to pick a color
- Or type hex value (e.g., `#4A90E2`)
- 6 color categories to customize:
  1. Primary Accent (buttons, highlights)
  2. Secondary Background (panels)
  3. Borders (separators)
  4. Success (green)
  5. Danger (red)
  6. Warning (orange)
- 🔄 Reset Colors to restore defaults

#### ℹ️ **About** - App Information
- Version and features list
- Technology details

## 🔄 Reset Everything

If you mess up:
1. Settings → Any tab
2. Click 🔄 "Reset to Defaults"
3. Confirm the dialog
4. All customizations cleared
5. Returns to Dark theme

## 📝 Common Tasks

### Task: Change Save Folder
1. Click ⚙️ Settings
2. Go to General tab
3. Click 🗂️ Browse button
4. Select folder
5. Done! (auto-saved)

### Task: View Application Logs
1. Click ⚙️ Settings
2. Go to General tab
3. Click 📄 Open Log File
4. Folder opens in Explorer

### Task: Make UI Darker
1. Click ⚙️ Settings
2. Go to Colors tab
3. Lower "Primary Accent" value (darker color)
4. Instant preview!

### Task: Go Back to Light
1. Click ⚙️ Settings
2. Go to Theme tab
3. Select ☀️ Light
4. Done!

## ❓ Troubleshooting

### Settings Button Not Working?
- Make sure you click the gear ⚙️ symbol
- Should be in top bar of sidebar
- Try restarting the application

### Changes Not Applying?
- Click a different tab then back
- Try Close and reopen Settings
- Check that hex color is valid (6 digits after #)

### Want Defaults Back?
- Settings → Any tab → 🔄 Reset to Defaults
- Confirm dialog
- Everything resets

### Lost Your Settings?
- Delete: `~/.biometric_app/settings.json`
- Restart app
- All defaults restored
